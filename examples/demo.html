🔍 Extractor de Números de WhatsApp

📋 Instrucciones de uso:

  1. Abre WhatsApp Web en tu navegador
  2. Navega al grupo del cual deseas extraer números
  3. Abre la consola de desarrollador (F12)
  4. Copia y pega el contenido de script.js
  5. Presiona Enter y se descargará el archivo CSV

💡 Métodos disponibles:

Opción 1: Script de Consola

Copia el código de script.js y pégalo en la consola del navegador.

Opción 2: Bookmarklet

Arrastra este enlace a tu barra de marcadores:

📱 Extraer Números WhatsApp

📁 Formato de salida:

Los números se exportan en formato CSV con la siguiente estructura:

Número
+34 123 456 789
+34 987 654 321
+1 555 123 4567
